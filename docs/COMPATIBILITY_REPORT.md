The report is deliberately free of timestamps, tool versions and machine
paths, so a rerun with the same toolchain is byte-identical. The reference
is the runtime behaviour of the JavaScript emitted by `tsc` (which emits
even when it reports type errors); `type_error` records that deliberate
choice. Skipped cases are declared from `COMPATIBILITY.md` §6 and are not
executed. Known-difference cases pin both the reference output and the
expected NavaScript outcome (exact output or build failure), so an
arbitrary failure cannot count as a pass where an exact output is pinned.

## Known differences and skipped cases

### `async_arrows` — Async arrows and methods

- Expectation: skip (outcome: skip)
- Reason: Only async function declarations are parsed; async arrows/methods are diagnosed (ADR-0029).

### `bigint_log` — Bigint rendering in console.log

- Expectation: differ (outcome: pass)
- Reason: Node prints the n suffix (1n); NavaScript-backed bigints are i64 values and print as bare numbers (ADR-0022).
- Measured Node output: `1n`

### `catch_bindings` — Untyped catch bindings

- Expectation: skip (outcome: skip)
- Reason: NavaScript requires a type annotation on catch bindings, unlike JavaScript's untyped catch (ADR-0028).

### `class_field_initializers` — Class field initialisers

- Expectation: skip (outcome: skip)
- Reason: Fields are declared without initialisers; assign them in a constructor instead (ADR-0024).

### `conditional_types` — Conditional and mapped types

- Expectation: skip (outcome: skip)
- Reason: Conditional/mapped types are a long-term item; the checker has no conditional type syntax (COMPATIBILITY.md §6).

### `cross_function_exceptions` — Cross-function exception unwinding

- Expectation: skip (outcome: skip)
- Reason: A throw must have a handler in the same function; unwinding through a called function needs a runtime ABI (ADR-0028).

### `d_ts_resolution` — .d.ts and package resolution

- Expectation: skip (outcome: skip)
- Reason: Only relative .ns (or extensionless) specifiers are resolved from the entry file; .d.ts and package resolution remain unsupported long-term work (ADR-0026).

### `decorators` — Decorators

- Expectation: skip (outcome: skip)
- Reason: Decorators are deferred and outside the initial language scope (COMPATIBILITY.md §6).

### `float_format` — Floating-point result formatting

- Expectation: differ (outcome: pass)
- Reason: Node prints the shortest round-trip representation (0.30000000000000004); the NavaScript runtime formats a compact decimal (0.3).
- Measured Node output: `0.30000000000000004`

### `general_iterables` — for-of over general iterables

- Expectation: skip (outcome: skip)
- Reason: Only arrays and strings are lowered to index loops; objects and custom iterables are unsupported (COMPATIBILITY.md §6).

### `jsx` — JSX / TSX

- Expectation: skip (outcome: skip)
- Reason: There is no DOM/UI target, so .nsx/.tsx syntax is deferred (COMPATIBILITY.md §6).

### `lib_dt` — Full lib.d.ts surface

- Expectation: skip (outcome: skip)
- Reason: The standard library exposes console, strings, arrays, objects, bigint helpers, synchronous promises, file I/O, argv, tagged values and explicit collection; Array.prototype.map and the rest of lib.d.ts remain long-term work.

### `node_interop` — Node.js CommonJS interop

- Expectation: differ (outcome: pass)
- Reason: Node resolves require("path") at runtime; NavaScript emits a standalone native executable with no Node runtime, so require is diagnosed.
- Measured Node output: `object`

### `object_log` — console.log of object and array values

- Expectation: differ (outcome: pass)
- Reason: Node pretty-prints objects and arrays; NavaScript has no structured console representation and emits raw slot bytes.
- Measured Node output: `{ a: 1 }
[ 1, 2 ]`

### `optional_nullable` — Optional chaining on a nullable receiver

- Expectation: differ (outcome: pass)
- Reason: Node short-circuits s?.length to undefined; NavaScript diagnoses a nullable optional-chain receiver even though IR has an IsNull branch (ADR-0025).
- Measured Node output: `undefined`

### `per_file_namespaces` — Per-file module namespaces

- Expectation: skip (outcome: skip)
- Reason: Imports are concatenated into one program, so names are module-wide rather than per-file; diagnostics refer to the combined source (ADR-0026).

### `promise_methods` — Promise combinators and methods

- Expectation: skip (outcome: skip)
- Reason: Promises are synchronous values; .then, .catch, Promise.resolve and Promise.all are not provided (ADR-0029).

### `stdlib_math` — Math standard-library object

- Expectation: differ (outcome: pass)
- Reason: Node provides Math.max; the NavaScript stdlib has no Math object, so the member call is diagnosed instead of executed.
- Measured Node output: `2`

### `type_error` — Incompatible assignment diagnostics

- Expectation: differ (outcome: pass)
- Reason: tsc emits JavaScript despite the error and Node prints the value; NavaScript treats type errors as build failures and produces no executable.
- Measured Node output: `not a number`

### `virtual_dispatch` — Virtual method dispatch

- Expectation: skip (outcome: skip)
- Reason: Class methods are mangled direct calls, so a base-typed reference calls the base implementation rather than the derived override (ADR-0024).
